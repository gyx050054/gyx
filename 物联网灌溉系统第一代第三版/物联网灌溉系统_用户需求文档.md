# 物联网灌溉系统 — 用户需求文档

## 1. 产品概述

本系统是一个面向农田灌溉管理的物联网平台,适用于中小型农户，用户可以通过客户端 Web 页面，实时查看田间设备的运行状态、历史数据，并对设备进行远程控制和定时任务管理。

---

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 管理员/农户 | 登录系统后，查看田块信息、管理田间设备、设置浇水任务 |

---

## 3. 功能需求（用户视角）

### 3.1 登录

- 用户打开客户端，首先看到的是**登录页面**。
- 输入用户名和密码，点击登录即可进入系统。
- 登录失败时有明确的错误提示（如账号或密码错误）。

### 3.2 田块总览

- 登录后进入**田块总览页面**，以卡片或列表形式展示所有田块。
- 每个田块卡片展示：
  - 田块名称
  - 田块中的设备总数（温度湿度计 + 电动阀合计）
- 用户可直观了解各田块的设备覆盖情况。

### 3.3 田块详情 — 设备列表

- 点击某个田块卡片，进入该田块的**设备列表页面**。
- 页面展示该田块下所有设备，分为两类：

  **温度湿度计**（每张卡片展示实时数据）：
  - 设备 ID
  - 当前温度（℃）
  - 当前湿度（%RH）
  - 安装田块
  - 最近一次数据上报时间

  **电动阀**（每张卡片展示当前状态）：
  - 当前状态：工作中 / 未工作
  - 设备电量（%）
  - 设备 ID

- 页面每隔 10 秒自动刷新设备状态，用户看到的是接近实时的数据。

### 3.4 温度湿度计 — 历史数据

- 点击某个温度湿度计设备卡片，进入**历史数据页面**。
- 页面以**折线图**展示该设备的历史温度、湿度变化趋势。
- 支持按时间范围筛选（如近 1 小时、近 24 小时、近 7 天、自定义时间段）。
- 鼠标悬停在图表上可查看具体数值和时间。
- 用**面可以看到温度随时间的变化曲线**，辅助判断灌溉需求。

### 3.5 电动阀控制

#### 3.5.1 单设备控制

- 在设备列表中，每个电动阀卡片上配有**开关按钮**。
- 点击按钮可直接开启或关闭该电动阀。
- 操作后有明确的**成功/失败反馈**。

#### 3.5.2 批量控制

- 在设备列表页面，用户可**多选**多个电动阀。
- 选中后出现批量操作栏，提供：
  - **一键全部开启** — 所有选中的电动阀立即开始浇水
  - **一键全部关闭** — 所有选中的电动阀立即停止浇水
- 批量操作同样有明确的成功/失败反馈。

### 3.6 定时浇水任务

#### 3.6.1 创建定时任务

- 用户可选择单个或多个电动阀，设置**定时浇水任务**。
- 设置内容：
  - 目标设备（已选设备自动带入）
  - 开始时间（默认立即开始，也可手动选择未来的时间）
  - 持续时长（如 30 分钟、1 小时、2 小时等）
- 设置完成后，系统会在指定时间自动开启浇水，到时间自动关闭。

#### 3.6.2 任务冲突处理

- 同一设备在设定的时间段内已有其他任务（等待执行 / 执行中）时，新任务将被**拒绝创建**，确保设备不会在同一时间收到矛盾指令。
- 批量添加时，任一设备存在冲突则**整体拒绝**，所有任务均不创建。
- 冲突检测规则：两个任务时间段有交集（`startTime1 < endTime2 && endTime1 > startTime2`）即判定冲突。

#### 3.6.3 任务管理

- 提供一个**任务管理页面**，用户可查看所有已创建的任务。
- 每个任务展示：
  - 任务 ID
  - 涉及的设备列表
  - 计划开始时间
  - 计划结束时间
  - 当前状态（等待执行 / 执行中 / 已完成 / 已取消）
- 用户可**取消**尚未执行或正在执行的任务。
- （未来规划）支持多用户同时操作时通过消息队列避免冲突。

### 3.7 设备状态实时更新

- 客户端每隔 10 秒自动刷新所有设备的当前状态（温度、湿度、阀门状态、电量等），用户无需手动刷新页面即可获取最新数据。
