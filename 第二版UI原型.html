📱 第二版 UI 原型说明

点击顶部按钮切换页面；阀门卡片上的开关可点击切换状态。

第二版核心页面（10 个）

  • 登录页：邮箱+密码，新增「注册」入口；下方提示演示账号
  • 注册页：注册即建租户+租户管理员，首次登录强制改密
  • 强制改密页：旧密码+新密码，改完才进主界面
  • 田块总览：卡片网格 + 右上角「＋」新增田块；长按删除
  • 田块详情：阀门卡片新 UI（大号渐变开关 + 流量/水压/电量数据行）、温湿度计大字卡片
  • 新增设备：名称 + 类型单选（仅电动阀/温度湿度计）+ 挂载田块下拉
  • 设备凭证：Access Token 展示/复制/二维码（真设备接入用）
  • 农户管理：租户管理员建农户账号（列表+新增+删除）
  • 任务管理：四态标识 + 取消；第二版按租户隔离
  • 我的：角色标识（租户管理员/农户）+ 改密 + 退出

角色权限差异

  • 租户管理员：全部功能（含新增/删除田块、设备、农户管理）
  • 农户：只能看数据、开关阀、设定时任务；无「＋」新增入口、无农户管理
