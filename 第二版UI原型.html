📱 第二版原型说明（基于第一版改造）

整体保留第一版 Material3 紫色主题、TopAppBar、底部导航、卡片式输入框。点击顶部按钮切换页面，阀门大开关可点击切换。

第二版在哪些地方"改"了第一版

  • ① 登录页：新增「注册租户」入口 + 演示账号提示；其余保持第一版
  • ② 注册页：新增页面（注册即建租户+管理员）
  • ③ 强制改密页：新增页面（首登必改，改完才进主界面）
  • ④ 田块总览：顶栏新增「＋」建田块、田块卡片右上删除 ✕；其余保持第一版网格
  • ⑤ 田块详情：阀门卡片升级（大号开关 + 流量/水压/电量数据行）；温湿度计保持第一版
  • ⑥ 新增设备：新增页面（类型仅电动阀/温度湿度计 + 挂载田块）
  • ⑦ 设备凭证：新增弹窗（Access Token 展示，真设备接入）
  • ⑧ 农户管理：新增页面（仅租户管理员可见）
  • ⑨ 任务管理：保持第一版样式；第二版按租户隔离
  • ⑩ 底部导航：第一版「田块/设备」→ 加「我的」（角色标识/改密/退出）

角色权限

  • 租户管理员：全部功能（＋新增田块/设备、农户管理）
  • 农户：可看数据、开关阀、设定时任务；无「＋」、无农户管理
